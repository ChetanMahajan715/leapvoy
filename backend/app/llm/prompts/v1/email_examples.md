# The user's own approved application emails (Oct 2026), used as STYLE examples for the email writer

Each block is one email, exactly as sent (links and phone normalised). `style_examples` drops any bullet the current
resume does not back before the AI sees it, so an old fact (e.g. a project no longer on the resume) is never copied.
